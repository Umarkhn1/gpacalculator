# TUIT GPA

Минималистичный калькулятор среднего балла на React с импортом оценок из LMS TUIT.
Разворачивается на Netlify — **свой сервер не нужен**.

Автор: **Umarkhn1**

## Возможности

- Расчёт GPA (взвешенное среднее оценки по кредитам), пересчёт на лету
- Добавление / удаление предметов, автосохранение в браузере
- **Импорт из LMS** — маленькое окно авторизации: вводите логин/пароль от `lms.tuit.uz`,
  выбираете семестр, оценки и кредиты подставляются в поля автоматически
- Светлая и тёмная тема

## Деплой на Netlify

1. Залейте репозиторий на GitHub.
2. На netlify.com → **Add new site → Import from GitHub** → выберите репозиторий.
3. Настройки сборки Netlify подхватит из `netlify.toml` автоматически:
   - Build command: `npm run build`
   - Publish: `dist`
   - Functions: `netlify/functions`
4. Deploy — всё готово.

Авторизация в LMS работает через serverless-функцию `netlify/functions/lms-import.mjs`,
которую Netlify запускает бесплатно. Отдельный сервер держать не нужно.

> Почему функция, а не запрос прямо из браузера: `lms.tuit.uz` не отдаёт CORS-заголовки,
> а cookie сессии — httponly. Поэтому логин и парсинг делаются на стороне Netlify.
> Логин/пароль нигде не сохраняются — используются только в момент импорта.

## Локальная разработка

```bash
npm install
npm run dev          # http://localhost:5173
```

Импорт из LMS работает и локально: Vite через свой dev-плагин запускает ту же
serverless-функцию, что и на Netlify, — отдельный сервер и netlify-cli не нужны.

## Структура

```
index.html                       точка входа Vite
src/App.jsx                      калькулятор
src/ImportModal.jsx              окно авторизации + выбор семестра
src/styles.css                   дизайн (светлая/тёмная тема)
netlify/functions/lms-import.mjs serverless-функция: логин в LMS + парсинг оценок
netlify.toml                     конфигурация деплоя и редиректов
public/logo.png                  логотип TUIT
```
